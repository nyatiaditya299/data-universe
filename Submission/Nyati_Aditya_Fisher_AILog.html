AI Log: Data Universe (Fisher Investments, wealth-management track)

Aditya Nyati · MS Finance, UT Dallas · AI in Finance Week 2026 · all work created 25–26 Oct 2026 · public data only; no licensed or confidential data was used or sent to any AI tool

1. Task, tools and why

Claude (Anthropic), via Claude CodeTask: write, run and test the whole product (downloaders, parsers, ranking, interface), and drive a browser to check the running page. Opus 5.5 for the data, ranking, conclusion and clarifying-question work; Sonnet 5.5 for the interface redesign (to a design spec I supplied), sidebar, background and trace tree. Why: it runs the code and tests on my PC and looks at the real page, so each change was checked, not only written. I set the requirements and made the choices below.
GPT-OSS 20B (open-weight), free hosted by PollinationsTask: inside the product, read the 8–10 retrieved entries and write a short conclusion that cites them by number. Why: free, no account, open weights, so the same step can later run on a firm's own machine. Only public data and my public test questions were sent to it. Claude as the conclusion writer stays an optional setting.

3. Checks

1. Against sourceBerkshire Q2 2026 13F total recomputed as $299.25B = the raw SEC filing. The CAPE conclusion's figures (30.81, average 17.40, 44.20 in Dec 1999, above 95% of readings) = the cited data sheet.
2. Edge case“What did the FOMC say about inflation in 2023?” → the model said the statements held no inflation comment. Cause: a press-contact line (“Implementation Note issued … 2023”) outranked the real statements. Removed it; retest cited the May, June, July and September 2023 statements (4 valid citations). Regression test added.
3. Held-out test81 unseen questions, untrained vs trained ranking: right source in top 3 84% → 93%, ranked first 73% → 83%. Limit: questions are auto-generated, so this tests finding the source, not answer quality.
4. Invented citationsA made-up citation is stripped and counted (unit test). In about half of my live test runs the model skipped citations (and twice said no inflation target was mentioned although the statements state 2%), so an answer with no valid citation is now forced to “low confidence”. 27 automated tests pass.
5. Source integrityLoading Fisher's documents, I found two files labelled as Fisher articles that held SEC 13F tables, and two more with only site menus. I replaced them with the real page text; a question on Fisher's top-down process now returns that page first and the conclusion cites it.

Prompts 3, 4 and 6 are quoted as typed; prompts 1 and 2 are summarised from the project handover.

4. Accepted, changed, rejected

Accepted

  • Retrieval plus a cited conclusion, not fine-tuning.
  • Ranked options come from the search, not the model.
  • A free open model, for public data only.

Changed

  • Prompt uses source numbers [1], [2] mapped back to real passage IDs.
  • Uncited conclusion capped at low confidence.
  • FOMC boilerplate cut; free model made the default.

Rejected

  • Any sentence without a valid source, and “not mentioned” claims left unchecked.
  • IMF and AAII data (downloads blocked, HTTP 403); bank outlook PDFs (reuse terms, manual only).
  • Fine-tuning; any confidential data in a public AI tool.

Limits: no access to a firm's internal advice data, so this runs on public proxies; the free model is rate-limited (one reply per 30 s) and sends text to a third party, so a firm would host a model locally for speed and data protection. 13F filings are delayed snapshots with no reasons. Nothing here is investment advice.
